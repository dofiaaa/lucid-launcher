## ✨ Особенности

**Lucid Launcher** — это не просто альтернатива системному рабочему столу. Это **красивая, лёгкая и неперегруженная оболочка**, которая полностью убирает визуальный шум, оставляя только самое необходимое для комфортной работы и развлечений.

*   🧘 **Минимализм и чистота**: Никаких лишних виджетов, навязчивых рекомендаций или визуального мусора. Только вы, ваши приложения и эстетичный интерфейс.
*   🪶 **Сверхлёгкий (Zero-Bloat)**: Размер APK — около 60 КБ. Ноль внешних зависимостей (никакого AndroidX, только чистый Android Framework). Потребление ОЗУ — минимальное.
*   💎 **Lucid Glass UI**: Современный дизайн с эффектом полупрозрачного стекла, размытием обоев и плавными градиентами.
*   📺 **Идеально для пультов и геймпадов**: Полноценная поддержка навигации D-pad. Крупные элементы, понятный фокус.
*   🖼️ **Кастомные обои**: Выбор картинки из галереи, регулировка размытия (0–100%) и силы затемнения.
*   ⚙️ **Удобные настройки**: 
    *   Размер иконок (S / M / L).
    *   Прозрачность стекла.
    *   Скрытие лишних приложений из сетки.
    *   Сортировка по алфавиту или по частоте запуска.
*   🕒 **Часы и дата**: Настраиваемый формат (12/24 часа).

## 🚀 Установка

1. Перейдите в раздел [**Releases**](https://github.com/dofiaaa/lucid-launcher/releases) этого репозитория.
2. Скачайте последний файл `Lucid-debug.apk`.
3. Установите его на планшет или ТВ-приставку (разрешите установку из неизвестных источников).
4. Нажмите кнопку **«Домой»** на устройстве и выберите **Lucid** в качестве лаунчера по умолчанию (нажмите **«Всегда»**).
